Browser tools for authoring the audio side of the exhibit: the DSP sequencer patterns and the synth patches that feed the Daisy.

Sequencer .pat grid

Edit the drum grid, stab/bass lanes, and chord progression for a song's pattern.

Patches FM stab · rumble bass

Tune the synth-voice parameters (mod ratio, index, envelopes, filter, …).
The .pat grid format is slated to migrate to MIDI. When it does, only shared/patfile.js changes — the editor speaks an in-memory pattern object, not .pat syntax.
